# Floor Planner

A simple room planner that runs in the browser. Type in room measurements, divide the space with walls, and add doors, windows, furniture, sockets and switches.

Everything is in `index.html`. There's no build step and no server.

## Saving
- **This browser:** plans save automatically.
- **Another computer:** click **Copy link**, send the link to yourself, and open it there. The whole plan is inside the link, and nothing gets uploaded. If a computer already has an older copy, the link updates it. If that copy is newer, the link's version is added as a separate copy.
- **Backup:** use Save / export → Save to file (.json), then Open file to load it back.
